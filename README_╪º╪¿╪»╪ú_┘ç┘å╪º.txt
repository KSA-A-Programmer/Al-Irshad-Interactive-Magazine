مجلة مدرستنا – العدد الثاني – نسخة تفاعلية تجريبية
=================================================

النسخة تحتوي على صفحات المجلة الأصلية الـ29 دون تغيير أي نص أو تصميم أو صورة.
تُعرض الصفحات كصور مطابقة للـ PDF، وتضاف الإجابات كطبقة منفصلة فوقها.
ملف original.pdf موجود دون تعديل للرجوع إلى الأصل.

التشغيل:
1) فك الضغط عن ZIP.
2) ارفع محتويات مجلد interactive_magazine إلى مستودع GitHub جديد.
3) Settings > Pages > Deploy from a branch > main / root > Save.
4) افتح رابط GitHub Pages المنشور. لا تستخدم فتح index.html مباشرة من الجهاز؛ لأن إعدادات المتصفح قد تمنع بعض الميزات.
5) انقر في أماكن الإجابات أو استخدم زر «إضافة كتابة» لتحديد أي موضع إضافي.
6) «حفظ PDF» يفتح طباعة المتصفح: اختر Save as PDF / حفظ PDF، حجم A4، هوامش بلا، ومقياس 100%.
7) الحفظ التلقائي المحلي يعمل على نفس المتصفح والجهاز فقط؛ مسح بيانات المتصفح يمسح الإجابات.

إعداد Google Sheets (الحساب المطلوب: Lulu.y.a80@gmail.com):
1) سجل الدخول إلى حساب Lulu.y.a80@gmail.com، وأنشئ جدول بيانات جديدًا.
2) من الجدول: الإضافات > Apps Script (Extensions > Apps Script).
3) انسخ محتويات Google_Apps_Script.gs إلى المحرر واحفظ.
4) نشر > عملية نشر جديدة > تطبيق ويب (Deploy > New deployment > Web app).
5) Execute as: Me / التنفيذ بصفتي؛ Who has access: Anyone / أي شخص.
6) وافق على أذونات Google المطلوبة. انسخ عنوان Web App الذي ينتهي بـ /exec.
7) افتح المجلة واضغط «إرسال الإجابات»؛ ألصق رابط /exec عند الطلب ثم اضغط «إرسال الإجابات» مرة أخرى.
8) تحقق من ظهور الإجابات في ورقة «إجابات المجلة» في Google Sheets.

مهم جدًا:
- تم تحديد Lulu.y.a80@gmail.com كحساب الاستقبال المستهدف فقط؛ الربط الفعلي لا يعمل حتى نشر Apps Script من الحساب وإدخال رابط /exec.
- لا يمكن للمجلة أن تؤكد نجاح التسجيل بسبب قيود CORS في تطبيق Google Apps Script العام؛ افحص الجدول بعد الاختبار.
- واجهة Google Apps Script المنشورة بهذه الطريقة متاحة للعامة وقد تتلقى إدخالات غير مرغوبة؛ استخدمها للتجربة فقط دون بيانات شخصية لطالبات.
- لا تجمع أسماء أو أرقام هواتف أو أي معلومات شخصية للطالبات في النسخة التجريبية.
- عند الانتقال لحساب المدرسة الرسمي: أنشئ جدولًا ونشرًا جديدًا، ثم غيّر رابط Web App في المتصفح عبر أدوات المطور أو امسح إعدادات الموقع، أو عدّل المفتاح magazine-google-script-url في Local Storage.
- لا تشارك جدول البيانات علنًا. هذا النظام لا يثبت هوية مرسل الإجابات.
- بعض المربعات تحتاج إلى معايرة دقيقة بعد تجربة حقيقية على جهاز المدرسة؛ توجد أداة «إضافة كتابة» و«إضافة علامة» لتغطية أي موضع غير مجهز.
- المجلة هنا صفحة واحدة في كل مرة للحفاظ على سهولة إدخال الإجابات، وليست محاكاة ثلاثية الأبعاد لتقليب الورق.
